# Milestone 212 - AI Chat Local Replay Runs

## Status

Verified.

## Summary

Workspace-bound AI dialog now handles `/runs`, `/replay-runs`, and `/run-history` locally. The command reads `replay/events.db` only through the read-only SQLite path and returns a compact Mission Conversation response:

```text
replay runs: runs=2 latest=run-b stored=false
```

If the replay database is absent, the command reports `runs=0 latest=none stored=false` without creating `replay/events.db`. The local response is metadata-only, not persisted, and excluded from later provider history.

## Safety Boundary

The command does not require provider setup, call provider generation, write provider usage records, write replay events, create model-generation artifacts, create model tool-plan preview artifacts, create compile-preview reviews, create execution dispatches, dispatch workers, execute tools, leak API key values, or contact targets.

The response is summary-only. It does not include workspace paths, database paths, artifact paths, command strings, provider URLs, prompt text, assistant text, raw provider bodies, bearer tokens, or API key values.
