# Milestone Progress Documents

Write one progress document for every completed milestone or implementation phase.

## Naming

Use this path pattern:

```text
docs/progress/milestone-XX-<slug>.md
```

Example:

```text
docs/progress/milestone-00-project-foundation.md
```

## Required Template

```markdown
# Milestone XX: <Name>

## Implemented
- List concrete modules, commands, files, and behaviors completed.

## Not Implemented
- List planned capabilities still missing or intentionally deferred.

## Validation
- List commands run, test results, and manual checks.

## Next Step
- Name the exact next milestone or task.

## Risks / Decisions
- Record blockers, tradeoffs, architecture decisions, and unresolved questions.
```

Do not mark a milestone complete in the implementation plan until this document exists.
