# Milestone 207 - AI Chat Local Context Command

## Status

Verified.

## Summary

Workspace-bound AI dialog now handles `/context` and `/workspace-context` locally. The command returns the compact read-only workspace context used by normal provider prompts as a Mission Conversation response:

```text
workspace context: workspace.context_status=available ... stored=false
```

The local response is metadata-only, not persisted, and excluded from later provider history.

## Safety Boundary

The command does not require provider setup, call provider generation, write replay events, write provider usage records, create model-generation artifacts, create model tool-plan preview artifacts, create compile-preview reviews, create execution dispatches, dispatch workers, execute tools, leak API key values, or contact targets.

The context projection remains limited to workflow status, mode, stage, next gate, reason, action, aggregate artifact counts, and safety-error count. It does not include workspace paths, command strings, provider URLs, prompt text, full assistant text, or API key values.
